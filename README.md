Este é um projeto simples feito como exercício do módulo de Bootstrap Avançado no curso de Engenharia Front-End da EBAC.

A proposta era praticar o uso de componentes do Bootstrap 5, como carrossel, grid, cards e modais. O conteúdo é baseado em personagens da saga Star Wars, escolhido apenas como tema ilustrativo.

## 🔧 Tecnologias utilizadas
- HTML5
- Bootstrap 5.3
- CSS básico embutido

## 💡 Funcionalidades implementadas
- Carrossel com imagens
- Cards com descrição de personagens
- Botão em cada card que abre um modal com mais informações
