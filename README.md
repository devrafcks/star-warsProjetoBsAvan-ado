Este projeto foi desenvolvido como parte da tarefa do módulo de **Bootstrap Avançado** no curso de Engenharia Front-End da **EBAC**.

O objetivo principal era aplicar na prática componentes do Bootstrap 5 — como carrossel, grid, cards e modais — dentro de um tema visual simples. O conteúdo de Star Wars foi usado apenas como referência estética.

## 🛠 Tecnologias utilizadas
- HTML5
- Bootstrap 5.3
- CSS básico (inline)

## ✨ Funcionalidades
- Carrossel com imagens no topo
- Cards com informações breves de personagens
- Modais com detalhes adicionais ao clicar nos botões dos cards
